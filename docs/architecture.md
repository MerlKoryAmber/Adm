# Архитектура admanager

## Назначение

Веб-панель управления и делегирования on-prem AD и Exchange 2019. Три функции: управление, делегирование, автоматизация. Апрув-workflow не входит.

## Слои (Clean/onion)

- **Domain** — сущности и правила, без внешних зависимостей.
- **Application** — интерфейсы (контракты) и use-cases. Оркестрирует, не знает про платформу.
- **Infrastructure.Ad / .Exchange / .Data / .Automation** — реализации контрактов.
- **Web (Blazor Server)** — UI + аутентификация + DI-композиция.

## Модель делегирования (из ADManager)

1. Приложение работает под одной **operational identity** (gMSA), которой точечно делегированы права AD + роли Exchange RBAC.
2. Техники прав в AD/Exchange не имеют, логинятся только в приложение (Windows SSO).
3. Собственный RBAC: роль = набор операций, scope = фильтр объектов (OU/группа).
4. На каждой операции `IRbacEngine` проверяет «техник в роли, роль включает операцию, объект в scope».
5. Операцию выполняет operational identity (не техник → нет double-hop). Всё — в аудит.

Граница безопасности — `IRbacEngine` + `IAuditLog`. RBAC обязан быть строгим, аудит — неизменяемым.

## Идентичность и Exchange

`Web` работает как gMSA (app pool). AD — прямой bind/Kerberos. Exchange — remote PowerShell к серверу Exchange 2019 (WSMan/Kerberos), пул runspace-ов. Подробнее и альтернатива с хранимой УЗ — `operations-model.md`.

## Автоматизация

`Infrastructure.Automation` — `BackgroundService`: планировщик + правила-триггеры. Типы задач: провижининг из CSV/HR, авто-дизейбл/чистка неактивных, синк членства групп, включение mailbox, атрибутные изменения, выгрузки. Каждая авто-операция проходит тот же core + RBAC + аудит.

## Данные

`Infrastructure.Data` (EF Core + SQL Server): роли, scope, назначения, аудит, конфиг доменов/кредов, определения автоматизаций.

## Фазы

- **Фаза 0 (PoC):** под gMSA сбросить пароль в тест-OU; через remote PS прочитать/изменить mailbox; запись в аудит.
- **Фаза 1:** ядро AD (одиночные операции) + аудит + Windows Auth.
- **Фаза 2:** движок делегирования (роли + scope) + портал техника.
- **Фаза 3:** операции Exchange.
- **Фаза 4:** bulk + automation.
